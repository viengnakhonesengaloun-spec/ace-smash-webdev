## Mô tả ngắn gọn về chủ đề website
Website gồm 3 trang:
1. **index.html** — Personal Portfolio: giới thiệu bản thân, kỹ năng (HTML/CSS/JS/Figma), và các dự án đã làm.
2. **store.html** — Landing Page cửa hàng dụng cụ cầu lông "ACE SMASH" (thương hiệu, sản phẩm nổi bật, khuyến mãi).
3. **product.html** — Trang chi tiết sản phẩm (thông số, đánh giá, mua hàng).

*(Bonus: `shop.html` — trang danh sách toàn bộ sản phẩm, có tìm kiếm/lọc theo danh mục.)*
