# ACE SMASH - Badminton Equipment Website

A responsive badminton e-commerce website designed based on the ACE SMASH Figma design.

## Features

- Responsive desktop and mobile layout
- Home page
- Shop page
- Product detail page
- Hero banner
- Featured products
- Shop by Brand
- Product cards
- Responsive navigation
- Footer with social media icons

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Pages

- index.html (Home)
- shop.html (Shop)
- product.html (Product Detail)
